# Pokedex

A small practice project built while learning and experimenting with Python, Pandas, NumPy, Matplotlib, and Seaborn.

The project uses Pokémon data to practice **data cleaning, exploration, analysis, and visualization** through different EDA techniques.

### Concepts Practiced

- Loading and inspecting datasets using Pandas
- Data cleaning and preprocessing
- Filtering and sorting data
- GroupBy and aggregation
- Creating derived columns
- Statistical analysis
- Data visualization using Matplotlib
- Data visualization using Seaborn
- Exploring relationships between variables
- Basic Exploratory Data Analysis (EDA)

This project is mainly a **hands-on practice exercise** to strengthen Python data analysis and visualization skills.
